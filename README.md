# 🌊 Foz do Iguaçu

> Uma experiência visual para descobrir um dos destinos naturais mais impressionantes do Brasil.

## ✨ Sobre o projeto

**Foz do Iguaçu** é uma Landing Page turística criada para apresentar as belezas naturais e os principais pontos turísticos da região.

A proposta foi desenvolver uma experiência **moderna, elegante e imersiva**, utilizando imagens em destaque, uma identidade visual inspirada na natureza e uma organização de conteúdo que incentive o visitante a explorar o destino.

Entre os principais locais apresentados estão:

🌊 **Cataratas do Iguaçu**
🦜 **Parque das Aves**
🌎 **Marco das Três Fronteiras**

---

## 🎨 Experiência

A página foi pensada para transmitir a sensação de estar explorando Foz do Iguaçu através da própria interface.

O projeto conta com:

* 🌿 Hero em tela cheia com destaque para as Cataratas;
* 🧭 Navegação entre as principais seções;
* 📖 Conteúdo sobre o destino;
* 🖼️ Imagens de grande destaque;
* ✨ Animações e efeitos de interação;
* 📱 Layout adaptado para diferentes dispositivos;
* 🎨 Identidade visual inspirada na natureza e nas paisagens da região.

---

## 🎯 Objetivo

Este projeto foi desenvolvido como parte de um **desafio prático da Rocketseat**, com o objetivo de transformar uma proposta de Landing Page turística em uma experiência visual funcional e responsiva.

Além de praticar os fundamentos de desenvolvimento Front-End, o projeto também busca explorar **hierarquia visual, composição, espaçamento, tipografia e experiência do usuário**.

---

## 🚀 Resultado

Uma Landing Page criada para destacar a beleza de Foz do Iguaçu de forma simples, moderna e envolvente.

> **Descubra. Explore. Viva. 🌿**
